# Product image uploads

Store product photos in this folder and reference them in `products.js`.

Suggested structure:

- `assets/products/p-001/1.webp`
- `assets/products/p-001/2.webp`
- `assets/products/p-001/3.webp`
- `assets/products/p-001/4.webp`

Guidelines:

- Prefer `.webp` format.
- Recommended width: `1200` to `1600` pixels.
- Keep each file ideally under `400 KB` for fast loading.
- Use descriptive alt-ready names where possible.
