How to Order

How to Order

Choose a catalog piece and move into a real order conversation in one step.

Available items on the catalog now include an Order now action. It opens a compact order window with WhatsApp, email, and Instagram options while carrying the product code and catalog price with you.

Go to Catalog View all contact channels

Ordering Flow

A clean path from browsing to confirmation.

01

Browse available items

Use the catalog filters, open the image gallery, and shortlist the item that fits your occasion, gifting plan, or design requirement.

02

Tap Order now

On every available item, the catalog opens a small order window with your preferred communication options already arranged.

03

Continue with the studio

We then confirm availability, sizing, timeline, pickup or delivery, and the next step toward final order confirmation.

What moves with you

Key product details are prepared before you leave the website.

  • Product code
  • Product name
  • Current catalog price
  • Availability status

Reference archive

Sold pieces stay visible for inspiration.

Some products remain on the catalog even after sale so customers can still review past design work, styling references, and the studio's creative direction. Those items are clearly marked as reference only and do not show the order flow.

Need help choosing?

If you are not sure what to order, start with the catalog anyway. The studio can help you narrow the right piece once you share the event, budget, and preferred style direction.
