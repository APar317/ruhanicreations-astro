How to read the catalog

  • Offer price shows the amount we would discuss for the currently available item.
  • Marked price shows the pre-discount catalog price where an offer is being highlighted.
  • Reference only marks sold pieces that remain visible for styling inspiration and archive viewing.

Ordering is now built into the catalog

Available items now include an Order now action. It opens a small window with WhatsApp, email, and Instagram options so the product code and catalog price move with you into the conversation.
